# HET Uzbekistan для Home Assistant

Кастомная интеграция получает из личного кабинета `cabinet.het.uz` три значения:

- текущий баланс (UZS);
- начисленные кВт⋅ч за текущий месяц;
- начисленную сумму за текущий месяц (UZS).

Интеграция использует JSON API сайта, не запускает браузер. Access token хранится только
в памяти, пароль — в защищённом хранилище config entries Home Assistant. При истечении
токена вход выполняется повторно автоматически.

Версия `1.0.1` и новее передаёт региональный `Coato-Code`, обязательный для получения
реальных значений. Без этого заголовка сервер HET возвращает успешный ответ с нулями.

## Установка вручную

1. Скопируйте папку `custom_components/het_uz` в `<config>/custom_components/het_uz`
   вашего Home Assistant.
2. Перезапустите Home Assistant.
3. Откройте **Настройки → Устройства и службы → Добавить интеграцию**.
4. Найдите **HET Uzbekistan**, введите логин и пароль личного кабинета.

По умолчанию данные обновляются каждые 15 минут. Интервал от 1 до 1440 минут меняется
через **Настроить** на карточке интеграции.

## Установка через HACS

1. Откройте **HACS → Integrations → меню ⋮ → Custom repositories**.
2. Добавьте `https://github.com/sherzodm13/ha-het-uz` с типом **Integration**.
3. Найдите и установите `HET Uzbekistan`, затем перезапустите Home Assistant.

## Примечания

Это неофициальная интеграция. Если HET изменит закрытое API, потребуется обновление.
Не публикуйте пароль, логи отладки или содержимое `.storage/core.config_entries`.
